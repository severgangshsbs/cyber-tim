# CYBER TIM — landing

Статический лендинг на чистом HTML/CSS/JS.

## Запуск
Открой `index.html` в браузере или загрузи папку в Vercel.

## Что внутри
- первый экран с реальными фото Cyber Tim;
- адаптив под мобильные;
- блок клуба/галерея;
- характеристики;
- режимы;
- statement-блок;
- отзывы-заглушки;
- адрес и ссылка на Яндекс Карты;
- лёгкие reveal-анимации.

Перед публикацией заменить отзывы-заглушки на подтверждённые актуальные отзывы и подключить реальную систему бронирования.
